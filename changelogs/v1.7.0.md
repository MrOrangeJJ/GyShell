# v1.7.0 Release Notes

## English

v1.7.0 is a major GyShell Agent performance release, with additional improvements to remote control and everyday reliability.

> [!IMPORTANT]
> 🚀 **Headline upgrade: dramatically faster GyShell Agent execution.** GyShell now safely runs supported, compatible tool calls in parallel, significantly reducing wait time in multi-tool and multi-machine tasks while keeping conflicting operations strictly ordered.

> [!TIP]
> **New: `gyll` command CLI.** Control GyShell sessions, chat, approvals, terminals, profiles, skills, tools, memory, and policies through stable JSON commands. Desktop releases include a standalone executable with no Node.js dependency; see the **[`gyll` installation and usage tutorial](../docs/cli-usage.md)**.

### What You Will Notice

- 🚀 **Major Agent speed boost** — Supported tool calls can now run safely in parallel, making multi-tool and multi-machine Agent tasks significantly faster without sacrificing execution safety.
- **Tune OpenAI-compatible requests per model** — Add typed text, number, boolean, or JSON request-body overrides for each model while GyShell keeps runtime-owned fields protected.
- **Trust long command results** — GyShell now distinguishes complete capture, incomplete capture, and display-only excerpts, and lets the Agent continue reading retained output instead of mistaking truncation for completion.
- **Cleaner Seamless activity** — The Seamless chat mode now presents tool work as compact, grayscale, multi-level disclosure with accurate warning and failure states.
- **Rename chat sessions everywhere** — Rename a session from the desktop Tab List or `gyll`; its new title is saved and appears live in connected clients.
- **Agent-managed terminal tabs** — Optional experimental tools let the Agent create tabs from saved Local/SSH connections and close tabs after you explicitly accept the risk.
- **Faster SSH-to-SSH file transfers** — Large single-file transfers between compatible Unix SSH hosts can go directly between the two machines, with automatic fallback to the existing relay path.
- **Agent Settings auto-save** — Changes made while an Agent Setting profile is active are written back to that profile automatically, so manual overwrite is no longer needed.
- **Cleaner tool settings** — Built-in tools now use short, user-friendly descriptions in Settings while keeping full instructions available to the Agent.
- **More predictable Skill discovery** — GyShell now scans only its managed Skills folder and `~/.agents/skills`; Skills in other compatibility folders are no longer loaded automatically.
- **More reliable multi-tool streaming** — Streamed tool-call IDs, indices, arguments, and results are reconciled before execution so multi-call turns are not silently merged or dropped.
- **Long-running Agents use memory more efficiently** — Checkpoint state is serialized at graph exit instead of after every intermediate step, and emergency context recovery can resume large histories from a durable reading frontier.
- **Stronger terminal and SSH recovery** — Startup, retries, reconnects, renderer remounts, output flow, and interactive input are handled more defensively, while private shell bootstrap and dispatcher traffic stay hidden.
- **More stable Windows terminals** — Cursor position and screen reflow remain synchronized when Windows terminal output and panel resizing happen at the same time.
- **Background SSH tabs stay monitorable** — SSH tabs created without a visible terminal panel can still bind to existing or future resource monitor panels.
- **Chat selection stays put** — Creating or attaching a chat tab in another panel no longer unexpectedly changes the session selected in your current chat panel.

## 中文

v1.7.0 是一次以 GyShell Agent 运行速度为核心的大版本优化，同时改进了远程控制与日常使用稳定性。

> [!IMPORTANT]
> 🚀 **本次核心更新：GyShell Agent 运行速度大幅提升。** GyShell 现在会安全地并行执行受支持且互不冲突的工具调用，显著缩短多工具、多机器任务的等待时间；存在冲突的操作仍会严格按安全顺序执行。

> [!TIP]
> **新增 `gyll` 纯命令 CLI。** 其他 Agent 现在可以通过稳定的 JSON 命令控制 GyShell 的会话、聊天、审批、终端、配置、Skills、工具、记忆和策略。桌面发行版内置无需 Node.js 的独立可执行文件，安装方式与完整示例请看 **[`gyll` 安装与使用教程](../docs/cli-usage.md)**。

### 你会直接感知到的更新

- 🚀 **Agent 运行速度大幅提升** — 受支持的工具调用现在可以安全并行执行，让多工具、多机器 Agent 任务明显更快，同时不牺牲执行安全性。
- **按模型定制 OpenAI 兼容请求** — 每个模型都可以添加文本、数字、布尔值或 JSON 类型的请求体覆盖字段，同时 GyShell 会保护由运行时管理的字段。
- **长命令输出状态更可信** — GyShell 现在会明确区分完整捕获、不完整捕获与仅展示节选；Agent 也能继续读取已保留的输出，不会把截断误判为执行完成。
- **Seamless 活动展示更清爽** — Seamless 聊天模式改用紧凑的灰阶多层展开结构展示工具活动，并准确标记警告与失败状态。
- **随时重命名聊天会话** — 可在桌面端 Tab List 或 `gyll` 中重命名；新标题会持久保存，并实时同步到已连接的客户端。
- **Agent 可管理终端标签** — 明确确认实验性风险后，Agent 可以从已保存的本地/SSH 连接创建终端标签，也可以关闭不再需要的标签。
- **SSH 机器间大文件传输更快** — 兼容的 Unix SSH 主机之间传输单个大文件时可直接在两台机器间复制；条件不满足时会自动回退到原有中转方式。
- **Agent Setting 自动保存** — 激活某个 Agent Setting 后，对配置所做的更改会自动写回该 Profile，不再需要手动覆盖保存。
- **工具设置更易读** — 设置页中的内置工具改用简短直观的说明，同时 Agent 仍能获得完整操作指引。
- **Skills 来源更明确** — GyShell 现在只扫描自身管理的 Skills 目录和 `~/.agents/skills`，不再自动加载其他兼容目录中的 Skills。
- **流式多工具调用更可靠** — 执行前会校准流式工具调用的 ID、序号、参数和结果，避免同一轮中的多个调用被静默合并或遗漏。
- **长任务内存使用更高效** — Agent 状态改为在执行图退出时统一序列化，不再每个中间步骤都重复写入；紧急上下文恢复也能从持久化阅读进度继续处理超长历史。
- **终端与 SSH 恢复更稳健** — 启动、重试、重连、界面重挂载、输出流控和交互输入采用更严格的状态保护，同时隐藏内部 shell 初始化与调度命令。
- **Windows 终端更稳定** — Windows 终端持续输出并同时调整面板大小时，光标位置和画面重排能保持同步。
- **后台 SSH 标签仍可监控** — 即使 SSH 标签创建时没有可见终端面板，也能绑定到已有或之后创建的资源监控面板。
- **聊天选中状态不乱跳** — 在其他面板创建或挂载聊天标签时，不会再意外切换当前聊天面板已选中的会话。
