# @gyshell/ui

Shared web UI package for GyShell desktop runtime.

Contains:

- React renderer app
- Theme/shared presentation modules used by renderer and Electron shell

Desktop terminals default to Classic and offer an opt-in Block view over the
same retained xterm runtime. Both views use the Terminal font, theme, and input
settings. See [Terminal Views and History](../../docs/terminal-views.md) for
renderer ownership, Activity markers, session restoration, and verification.
